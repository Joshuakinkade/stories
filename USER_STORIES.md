# User Stories

## Authentication & Registration

- As an admin, I can generate a single-use registration code so that I can invite a specific person to create an account.
- As a new user, I can register for an account using a single-use code provided by an admin, so that access to the site stays controlled.
- As a registered user, I can log in with my email and password so that I can access my account.

## User Gallery

- As a user, I have a public-facing gallery page that lists all of my published stories so that visitors can browse my work.
- As a user, I can set a title, avatar, and header photo for my gallery so that it reflects my identity.
- As a user, I can choose a color scheme for my gallery so that it has a consistent look and feel.
- As a user, I can make my gallery password protected so that only people I share the password with can view it.

## Story Access & Sharing

- As a user, I can set a story to public so that anyone can find and read it.
- As a user, I can set a story to anonymous link access so that only people with the link can read it.
- As a user, I can set a story to password protected so that readers must enter a password to view it.

## Page Browser (Editor Dashboard)

- As a user, I can view all of my stories in a paginated grid of thumbnail cards so that I can quickly find the one I want to work on.
- As a user, I can delete a story from the page browser so that I can remove work I no longer want.
- As a user, I can click an edit button on a story card to open that story in the editor.

## Editor

- As a user, I can drag and drop elements (photos, videos, text, maps, weather) onto a canvas so that I can build my story layout visually.
- As a user, elements I drop at the bottom of the page are placed into a new row automatically so that the page keeps growing naturally.
- As a user, elements I drop onto an existing row are inserted at the drop point so that I have precise control over ordering within a row.
- As a user, when I drop an element onto a full row, the last element in that row is pushed to a new row so that nothing gets lost.
- As a user, rows hold between 1 and 4 elements and elements expand to fill all available space in the row so that the layout always looks intentional.
- As a user, my changes are saved automatically as I make them so that I never lose work.
- As a user, I can browse the history of changes I have made to a story so that I can review or recover earlier versions.
- As a user, I can publish my story when I am ready so that the saved draft becomes publicly visible.
- As a user, I can pick a color scheme for my story so that styling — colors and typography — is applied consistently across the whole page.

## Published Pages

- As a reader, published pages load fast and feel lightweight so that I am not waiting around or draining my battery.
- As a reader, photos are served in efficient formats (WebP, HEIC) and at sizes appropriate to my screen so that pages load quickly.
- As a reader, I can tap a photo or video to expand it to full size inline (or in a lightbox) so that I can see the detail.
- As a reader, I can swipe between all photos on a page in the order they appear so that I can browse the story's images without leaving the page.
- As a reader, published pages display minimal branding — a small monochrome logo and breadcrumbs at the top and a "powered by" line at the bottom — so that the author's content stays front and center.
- As a reader, the branding on a published page uses the page's theme colors so that it blends with the overall design.
- As a user, my published pages are cached so that they load quickly for readers without rerendering on every request.
- As a user, the cache for my page is invalidated when I republish so that readers always see the latest version.

## Theming & Appearance

- As a user, I can choose a color scheme and typography for a story so that it has a distinctive look.
- As a user, the editor and site UI respond to my device's dark mode setting so that the interface is comfortable to use in any lighting.
