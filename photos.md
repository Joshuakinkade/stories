# Photos

This is the area of the API responsible for managing user' photo libraries. It supports uploading photos, with limits on size and format, saving them into albums, moving them between albums, and deleting them.

## Storage

Photos are primarily stored in an S3 compatible storage service. The Stories app also saves some photo information to the database. A UUID is generated in the library for each photo. This uuid is used as the primary key for the photo data and as the object name of the image file in storage.

## Retrieval

Photo URLs are dynamically generated by the React application when they are needed and can have size, quality, and format parameters attached. This allows the application to get images optimized the current usage and the user's device as they are needed without have to save multiple copies of the original photo ahead of time. The photo service does not save or cache these newly created photos anywhere. It assumes that there will be a separate cache between the user and the service that can cached the optimized images.
